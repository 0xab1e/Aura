## Example: Senior Software Engineer – Backend

**Company:** Acme Corp  
**Location:** Remote  

### About the Role
We are looking for a Senior Backend Engineer to join our platform team. You will design, build, and maintain scalable microservices that power our core product.

### Responsibilities
- Design and implement RESTful APIs and microservices in Python or Go
- Optimize database queries and data models (PostgreSQL, Redis)
- Own reliability: write tests, monitor production, respond to incidents
- Collaborate with cross-functional teams on architecture decisions
- Mentor junior engineers

### Required Skills
- 5+ years of backend engineering experience
- Strong Python or Go proficiency
- Experience with distributed systems and microservices
- SQL and NoSQL databases (PostgreSQL, Redis, MongoDB)
- Cloud infrastructure (AWS/GCP): EC2, S3, Lambda, Kubernetes
- CI/CD pipelines, Docker, Terraform
- System design: CAP theorem, eventual consistency, load balancing

### Nice to Have
- Experience with event streaming (Kafka, Kinesis)
- gRPC / Protocol Buffers
- Observability tooling (Prometheus, Grafana, Datadog)
